\# DukaanPro 🛍️



DukaanPro is a professional, offline-first shop management application designed for small business owners to track sales, manage expenses, and generate daily reports with ease.



\## 🚀 Features



\*   \*\*Secure Authentication:\*\* 6-digit PIN-based lock screen for data privacy.

\*   \*\*Animated UI:\*\* Modern splash screen featuring CSS-style floating particles and fire-glow effects.

\*   \*\*Offline Database:\*\* High-performance local storage using SQLite (`sqflite`).

\*   \*\*Shop Registration:\*\* Simple onboarding for shop details and owner information.

\*   \*\*Quick Sales (Coming Soon):\*\* Fast Entry system for rapid transaction recording.

\*   \*\*Business Intelligence (Coming Soon):\*\* Daily and monthly report generation with Excel export capabilities.



\## 🛠️ Tech Stack



\*   \*\*Frontend:\*\* \[Flutter](https://flutter.dev/) (Dart)

\*   \*\*State Management:\*\* \[Provider](https://pub.dev/packages/provider)

\*   \*\*Local Database:\*\* \[sqflite](https://pub.dev/packages/sqflite)

\*   \*\*Animations:\*\* \[Lottie](https://pub.dev/packages/lottie) and Custom Painters



\## 🏗️ Architecture



The project follows a clean, modular folder structure:

\- `lib/core`: Routing, services, and constants.

\- `lib/features`: Feature-specific UI (Splash, Auth, Dashboard).

\- `lib/data`: Models and local database repositories.

\- `lib/widgets`: Reusable UI components.
